# Mandala Computer Homebrew tap

```sh
brew install mandalacomputer/tap/mandala
```

Installs the `mandala` command-line client for [Mandala Computer](https://mandala.computer)
cloud desktops, from the published `mandala-computer` npm package, with bash, zsh and fish
completions.

The reviewed copy of the formula lives in
[`mandalacomputer/typescript-sdk`](https://github.com/mandalacomputer/typescript-sdk/tree/main/packaging/homebrew),
which also describes how it is bumped after each release. Keep the two identical.

Other ways to install: `npm install -g mandala-computer`, or
`curl -fsSL https://mandala.computer/install.sh | sh`.
